So far this release exports TipTap's extension classes from `tldraw`, so a custom rich text extension no longer needs its own `@tiptap/*` install. The rest is a broad reliability pass: crashes when shapes are deleted mid-interaction, selection and drawing edge cases, missing resources in exports, and a batch of store and sync fixes. `Editor.setCamera` now rejects non-finite values instead of quietly coercing them.

## What's new

### TipTap extension surface ([#10691](https://github.com/tldraw/tldraw/pull/10691))

Customizing rich text through `options.text.tipTapConfig.extensions` is public API, but the classes you need to write an extension were not exported. You had to add `@tiptap/core` to your own `package.json`, and a copy that does not dedupe against the one tldraw bundles gives you a second ProseMirror, which throws when the schema is built.

`tldraw` now re-exports `Node`, `Mark`, `Extension`, `mergeAttributes`, and `getSchema` from `@tiptap/core`, along with the `TaskList` and `TaskItem` extensions from `@tiptap/extension-list`. They come out of tldraw's own bundle, so they are single-instance by construction and locked to the TipTap version tldraw ships.

```tsx
// Before
import { Mark, mergeAttributes } from '@tiptap/core'
import { Tldraw, tipTapDefaultExtensions } from 'tldraw'

// After
import { Mark, Tldraw, mergeAttributes, tipTapDefaultExtensions } from 'tldraw'
```

`TaskList` and `TaskItem` are not in the default extension set, and tldraw does not style their checkboxes.

## API changes

- 💥 **`Editor.setCamera`** now throws on a non-finite `x`, `y`, or `z` instead of silently coercing it to `0` or the current zoom level, and no longer mutates the point object passed to it. ([#9903](https://github.com/tldraw/tldraw/pull/9903))
- 💥 **`store.query.filterHistory()`** now reports a change counter of its own instead of `store.history.get()`. After a rolled-back transaction it can be ahead of the store's counter, and it reports a change even for record types the transaction did not touch. Treat it as a change signal and read the content through `getDiffSince`. ([#10200](https://github.com/tldraw/tldraw/pull/10200))
- Add TipTap re-exports to `tldraw`: `Node`, `Mark`, `Extension`, `mergeAttributes`, `getSchema`, the `TaskList` and `TaskItem` extensions, and the `Extensions`, `JSONContent`, `TaskListOptions`, and `TaskItemOptions` types. ([#10691](https://github.com/tldraw/tldraw/pull/10691))
- Add `LruCache.delete(key)` to `@tldraw/utils`. ([#10338](https://github.com/tldraw/tldraw/pull/10338))

## Improvements

- Add support for `npm create tldraw .`, which scaffolds into the current directory and prompts when that directory is not empty. Also fixes `create-tldraw -t <template>` crashing on startup. ([#10657](https://github.com/tldraw/tldraw/pull/10657))

## Bug fixes

### Crashes

- Fix a crash that could replace the editor with the host app's error screen when a group's child record was removed during a transaction. Children that no longer resolve are skipped, and a group where none resolve falls back to a unit box. ([#10668](https://github.com/tldraw/tldraw/pull/10668))
- Fix a crash when a shape being translated, or the frame it is being dragged over, is deleted mid-drag. ([#10171](https://github.com/tldraw/tldraw/pull/10171))
- Fix a crash when a shape is deleted between pointing at it and starting to drag it or its handle. ([#10179](https://github.com/tldraw/tldraw/pull/10179))
- Fix the select tool bailing to an old history mark, or crashing, when a resize starts with nothing selected. ([#10165](https://github.com/tldraw/tldraw/pull/10165))
- Fix draw and highlight shapes created with no segments throwing in geometry and rendering. ([#10224](https://github.com/tldraw/tldraw/pull/10224))
- Fix a line shape with fewer than two points breaking hit testing for the whole page. ([#10222](https://github.com/tldraw/tldraw/pull/10222))
- Fix duplicating a zero-length line throwing. ([#10248](https://github.com/tldraw/tldraw/pull/10248))

- Fix Tab, Shift+Tab, and Ctrl/Cmd+arrow keyboard traversal selecting locked shapes, which clicking and select all never do. ([#10482](https://github.com/tldraw/tldraw/pull/10482))

- Fix a viewport deep link with a zero-size viewport parking the camera at the page origin instead of falling back to fitting the page content. ([#10628](https://github.com/tldraw/tldraw/pull/10628))

### Exports

- Fix exports missing referenced resources and fonts. Every resource is now embedded, failed fetches are retried, bare `@import` rules are followed, and stylesheets that import each other no longer hang the export. ([#10338](https://github.com/tldraw/tldraw/pull/10338))
