This release continues the reliability work across the SDK, with fixes to resizing, cursors, page duplication, the store, local persistence, and sync. It also adds a `ThrottledFunction` type to `@tldraw/utils`.

## API changes

- Add a `ThrottledFunction<T>` type to `@tldraw/utils`, also exported from `@tldraw/editor` and `tldraw`, for annotating the result of `throttle`. `throttle` is now declared to return it, so its published types no longer import lodash's. ([#10927](https://github.com/tldraw/tldraw/pull/10927))

## Improvements

- Reduce the thickness of hinted shape outlines, including the frame highlight shown while dragging shapes into a frame. ([#10952](https://github.com/tldraw/tldraw/pull/10952))

## Bug fixes

### Editor

- Fix duplicated pages repositioning their shapes when the content was off screen, and use the duplicated page's own camera rather than the current page's. ([#10465](https://github.com/tldraw/tldraw/pull/10465))
- Fix flipped children of rotated selections getting the wrong rotation, `onResizeStart` and `onResizeEnd` firing on every frame for unaligned shapes, and the fixed edge sliding when a `resizeBox` shape hits `maxWidth` or `maxHeight`. ([#10351](https://github.com/tldraw/tldraw/pull/10351))
- Fix `setCursor` throwing for the `rotate`, `resize-edge`, and `resize-corner` cursor types, and hex cursor colors in a theme breaking SVG cursors. ([#10350](https://github.com/tldraw/tldraw/pull/10350))
- Fix the arrow tool's precise mode carrying over to the next target. ([#10244](https://github.com/tldraw/tldraw/pull/10244))
- Fix held Cmd+Shift+arrow key combinations switching from parent and child selection to adjacent selection once the key repeats. ([#10184](https://github.com/tldraw/tldraw/pull/10184))
- Fix edits being lost when an editor remounts on the same persistence key while the previous client is still saving, as in React strict mode. ([#10752](https://github.com/tldraw/tldraw/pull/10752))

### Store

- Fix reactions that write to the store re-running on every unrelated store change, which could loop until the reaction update depth limit was exceeded. ([#10236](https://github.com/tldraw/tldraw/pull/10236))
- Fix store changes made in the last frame before a listener is removed never reaching that listener. ([#10802](https://github.com/tldraw/tldraw/pull/10802))
- Fix undo restoring an intermediate state after a `put` that updated the same record twice. ([#10203](https://github.com/tldraw/tldraw/pull/10203))
- Fix `migrateStoreSnapshot` throwing instead of returning a migration error for malformed persisted schemas. ([#10220](https://github.com/tldraw/tldraw/pull/10220))
- Fix retroactive migrations rerunning on already-migrated records when a persisted schema has a non-number sequence version. ([#10917](https://github.com/tldraw/tldraw/pull/10917))

### Sync

- Fix `undefined` prop values getting the session kicked with `INVALID_RECORD`, and ignore `__proto__` keys in incoming diffs. ([#10118](https://github.com/tldraw/tldraw/pull/10118))
- Fix clients on protocol version 7 silently desyncing on text edits from newer clients. ([#10095](https://github.com/tldraw/tldraw/pull/10095))
- Fix a resumed session skipping the handshake's schema checks, so a session the server could no longer reconcile after a redeploy was served unmigrated diffs. ([#10122](https://github.com/tldraw/tldraw/pull/10122))
