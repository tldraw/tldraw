This release exports TipTap's extension classes from `tldraw`, so a custom rich text extension no longer needs its own `@tiptap/*` install. The rest of the release continues the reliability pass: shapes now keep changes made by other commands while they are being dragged, resized, rotated, or cropped; crashes during drags and group edits are fixed; and there are batches of fixes for selection and keyboard navigation, exports, local persistence, and sync.

## What's new

### TipTap extensions without a second TipTap ([#10691](https://github.com/tldraw/tldraw/pull/10691))

Customizing rich text through `options.text.tipTapConfig.extensions` has always been public API, but the classes you need to build an extension — `Node`, `Mark`, `Extension` — weren't exported. You had to add `@tiptap/core` to your own `package.json`, and a version that didn't dedupe against the one tldraw bundles gave you a second ProseMirror. ProseMirror throws when a schema is built from nodes belonging to two instances, so the failure showed up at schema build time rather than at install time.

These re-exports come out of tldraw's own bundle, so they're single-instance by construction and version-locked to the TipTap version tldraw ships.

```tsx
// Before
import { Mark, mergeAttributes } from '@tiptap/core'
import { Tldraw, tipTapDefaultExtensions } from 'tldraw'

// After
import { Mark, Tldraw, mergeAttributes, tipTapDefaultExtensions } from 'tldraw'
```

The `TaskList` and `TaskItem` extensions come along too. They aren't in the default extension set, and tldraw doesn't style their checkboxes.

## API changes

- 💥 **`Editor.setCamera`** now throws on a non-finite `x`, `y`, or `z` instead of silently coercing it to `0` or the current zoom level, and no longer mutates the point object passed to it. ([#9903](https://github.com/tldraw/tldraw/pull/9903))
- 💥 **`store.query.filterHistory()`** now returns a change counter that no longer always equals `store.history.get()`. After a rolled-back transaction it can be ahead of the store's counter, and it reports a change even for record types the transaction didn't touch. ([#10200](https://github.com/tldraw/tldraw/pull/10200))
- Add re-exports of TipTap's `Node`, `Mark`, `Extension`, `mergeAttributes`, and `getSchema`, the `TaskList` and `TaskItem` extensions, and the `Extensions`, `JSONContent`, `TaskListOptions`, and `TaskItemOptions` types. ([#10691](https://github.com/tldraw/tldraw/pull/10691))

## Improvements

- Add support for `npm create tldraw .` to scaffold into the current directory, with a prompt when the directory is not empty. This also fixes `create-tldraw -t <template>` crashing on startup. ([#10657](https://github.com/tldraw/tldraw/pull/10657))
- Update the AI starter kit templates to current Claude, Gemini, and GPT model ids. ([#10058](https://github.com/tldraw/tldraw/pull/10058))

## Bug fixes

- Fix a crash that could replace the editor with the host app's error screen when a group's child record was removed during a transaction. Children that no longer resolve are skipped, and a group where none resolve falls back to a unit box. ([#10668](https://github.com/tldraw/tldraw/pull/10668))
- Fix a crash when a shape was deleted between pointing at it and starting to drag it or its handle. ([#10179](https://github.com/tldraw/tldraw/pull/10179))
- Fix a crash when a shape being translated, or the frame it was being dragged over, was deleted mid-drag. ([#10171](https://github.com/tldraw/tldraw/pull/10171))
- Fix the select tool bailing to an old history mark, or crashing, when a resize started with nothing selected. ([#10165](https://github.com/tldraw/tldraw/pull/10165))
- Fix draw and highlight shapes created with no segments throwing in geometry and rendering. ([#10224](https://github.com/tldraw/tldraw/pull/10224))
- Fix a line shape with fewer than two points breaking hit testing for the whole page. ([#10222](https://github.com/tldraw/tldraw/pull/10222))
- Fix duplicating a zero-length line throwing. ([#10248](https://github.com/tldraw/tldraw/pull/10248))

### Persistence and sync

- Fix local persistence silently dropping edits: changes another tab made while this one was still loading, edits queued in the last few hundred milliseconds before unmount, and writes still in flight when the database closed. ([#10332](https://github.com/tldraw/tldraw/pull/10332))
- Fix sync stalling permanently when `getUri` rejected, which in the documented `useSync` pattern is an auth-token fetch. A rejected `getUri` is now retried on the normal backoff, and a closed `ClientWebSocketAdapter` no longer notifies listeners or reconnects after disposal. ([#10107](https://github.com/tldraw/tldraw/pull/10107))
- Fix `useSync` still reporting a previous room's error after the `uri` changed to a new, healthy room. ([#10108](https://github.com/tldraw/tldraw/pull/10108))
- Fix `TLSocketRoom.updateStore` not seeing or deleting object-lane records. ([#10114](https://github.com/tldraw/tldraw/pull/10114))

- Fix `TLSyncRoom.close()` leaving per-session timers that could send into closed sockets or emit `session_removed` and `room_became_empty` on a closed room. A socket that throws on close no longer leaves the rest open. ([#10120](https://github.com/tldraw/tldraw/pull/10120))
