This release fixes a batch of bugs across the editor, including camera speeds on high-refresh displays, rotated image cropping, embed hostname matching, geometry precision, keyboard shape navigation, and theme handling.

## Bug fixes

- Fix camera coasting and edge scrolling running faster on high-refresh displays. ([#10501](https://github.com/tldraw/tldraw/pull/10501))
- Fix rotated images jumping on the canvas when their aspect ratio or crop zoom changes. ([#10233](https://github.com/tldraw/tldraw/pull/10233))
- Fix embed hostname matching so lookalike hosts no longer get a trusted definition's iframe permissions. ([#10196](https://github.com/tldraw/tldraw/pull/10196))
- Fix geometry hit tests losing precision after a shape's SVG path data was generated. ([#10600](https://github.com/tldraw/tldraw/pull/10600))
- Fix keyboard shape navigation selecting the wrong shape when navigating backward with no selection. ([#10601](https://github.com/tldraw/tldraw/pull/10601))
- Fix `getCurrentTheme()` returning `undefined` after `setCurrentTheme()` was called with an unregistered theme id. ([#10602](https://github.com/tldraw/tldraw/pull/10602))
- Fix `Group2d.transform` dropping ignored children, resetting the `isInternal`, `excludeFromShapeBounds`, and `isEmptyLabel` flags, and ignoring the `opts` argument. ([#10603](https://github.com/tldraw/tldraw/pull/10603))
