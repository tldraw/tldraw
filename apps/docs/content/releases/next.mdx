This release adds a `center` option for aligning shapes on both axes and deprecates `useViewportHeight`. It also fixes a batch of crashes and interaction bugs across wheel input, modifier keys, frame headings, and keyboard shortcut tooltips.

## API changes

- 🔜 **`useViewportHeight()`** is deprecated. Read `window.visualViewport` directly instead. The hook only ever returned the visible viewport's bottom edge, and it has shipped with no callers since v3.14. ([#9826](https://github.com/tldraw/tldraw/pull/9826))
- Add `'center'` as an `Editor.alignShapes` operation, which applies the existing `'center-horizontal'` and `'center-vertical'` operations together. ([#9074](https://github.com/tldraw/tldraw/pull/9074))

  ```ts
  editor.alignShapes(editor.getSelectedShapeIds(), 'center')
  ```

## Bug fixes

- Fix the "Rotate counterclockwise" tooltip not showing its comma key. Shortcut formatting now understands literal comma keys, using the same comma-aware splitting as keyboard registration. ([#9772](https://github.com/tldraw/tldraw/pull/9772))
- Fix a crash when panning with the wheel on devices that report non-finite wheel deltas, which wrote `NaN` to the camera and failed validation. Non-finite deltas are now coerced to zero at the input boundary, so the event becomes a no-op. ([#9586](https://github.com/tldraw/tldraw/pull/9586))
- Fix modifier keys (shift, alt, ctrl, cmd) briefly being treated as held at the start of a new click or drag right after being released, which could momentarily affect snapping and other modifier-dependent behavior. ([#9523](https://github.com/tldraw/tldraw/pull/9523))
- Fix a crash when computing a frame's geometry if its heading text couldn't be measured yet. ([#9496](https://github.com/tldraw/tldraw/pull/9496))
