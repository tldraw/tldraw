This release exports TipTap's extension surface from `tldraw`, so custom rich text extensions no longer need their own `@tiptap/*` install. It also lets `create-tldraw` scaffold into the current directory, and lands a broad reliability pass across selection and tools, the draw and line shapes, exports, sync, the store and signals layers, and mermaid diagram conversion.

## What's new

### Custom rich text extensions without a TipTap install ([#10691](https://github.com/tldraw/tldraw/pull/10691))

Writing a custom rich text extension meant adding `@tiptap/core` to your own dependencies and keeping its version in lockstep with ours — a mismatch produced two copies of TipTap and a schema that silently rejected your nodes. The `tldraw` package now re-exports the pieces you need to build one, so there is a single TipTap in the tree and no version to track.

```tsx
import { Node, mergeAttributes, TaskList, TaskItem } from 'tldraw'

const Callout = Node.create({
	name: 'callout',
	group: 'block',
	content: 'inline*',
	renderHTML({ HTMLAttributes }) {
		return ['div', mergeAttributes(HTMLAttributes, { class: 'callout' }), 0]
	},
})
```

`Node`, `Mark`, `Extension`, `mergeAttributes`, `getSchema`, and the `Extensions` and `JSONContent` types come from `@tiptap/core`. `TaskList` and `TaskItem`, with their options types, come from `@tiptap/extension-list`.

## API changes

- 💥 **`Editor.setCamera`** now throws on non-finite `x`, `y` or `z` instead of silently coercing them to `0` or the current zoom. It also no longer mutates the point object passed to it. ([#9903](https://github.com/tldraw/tldraw/pull/9903))
- 💥 **`store.query.filterHistory()`** now returns a change counter that no longer always equals `store.history.get()`. After a rolled-back transaction it can be ahead of the store's counter, and it reports a change even for record types the transaction didn't touch. ([#10200](https://github.com/tldraw/tldraw/pull/10200))
- Add re-exports of TipTap's `Node`, `Mark`, `Extension`, `mergeAttributes` and `getSchema`, the `Extensions` and `JSONContent` types, and the `TaskList` and `TaskItem` extensions with their options types. ([#10691](https://github.com/tldraw/tldraw/pull/10691))
- Add `MESSAGE_TOO_LARGE` to `TLSyncErrorCloseEventReason`. Apps that switch on the reason to pick an error message will want a case for it; an older client doesn't recognise the string but still reports `error`, because its status comes from close code 4099. The non-idle branch of `JsonChunkAssembler.state` also gains a required `charsReceived` field, so code that constructs that state by hand no longer type-checks. ([#10810](https://github.com/tldraw/tldraw/pull/10810))
- Add `LruCache.delete(key)` to `@tldraw/utils`. ([#10338](https://github.com/tldraw/tldraw/pull/10338))
- Add an optional `background` flag to `MermaidBlueprintNode`. `renderBlueprint` sends flagged nodes behind the blueprint's lines, so a filled node can span lifelines without hiding them. ([#10813](https://github.com/tldraw/tldraw/pull/10813))
- Add `anchorStartX` and `anchorEndX` to `MermaidBlueprintEdge`, horizontal counterparts to the existing `anchorStartY` and `anchorEndY`. ([#10773](https://github.com/tldraw/tldraw/pull/10773))

## Improvements

- Run `npm create tldraw .` to scaffold into the current directory, with a prompt when the directory is not empty. ([#10657](https://github.com/tldraw/tldraw/pull/10657))
- Use Cmd (Mac) or Ctrl to toggle snapping while dragging handles and wrap mode while brush selecting, matching translate, resize, and crop. ([#10172](https://github.com/tldraw/tldraw/pull/10172))
