This release introduces ICU MessageFormat and react-intl for translations, action-driven menu gating, and a `ThrottledFunction` type in `@tldraw/utils`. It also improves commenting, canvas navigation, and the select tool, and includes a broad set of bug fixes across selection, undo/redo, local persistence, sync, and the store.

## What's new

### ICU MessageFormat and react-intl for translations ([#8036](https://github.com/tldraw/tldraw/pull/8036))

The SDK's UI strings now use [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/), allowing messages to support pluralization, selections, and values interpolation cleanly across languages. We've also added react-intl authoring on top: `defineMessages` and `<F>` declare and render messages with their default English next to the code that uses them.

Existing translations overridden by ID through `overrides.translations` continue to work unchanged.

## API changes

- Add ICU MessageFormat translation support with `defineMessages`, `<F>`, and `useTldrawI18n`. `useTranslation`'s `msg` now supports interpolating values through an optional second argument and accepts declared message descriptors. ([#8036](https://github.com/tldraw/tldraw/pull/8036))
- Add `isAvailable(editor)`, `isEnabled(editor)` and `isChecked(editor)` to actions. Menu items built with `TldrawUiMenuActionItem` and `TldrawUiMenuActionCheckboxItem` read them: an unavailable action is hidden, a disabled one is greyed out or hidden depending on `whenDisabled: 'hide' | 'disable'`. `useSomeActionsEnabled` returns whether any of the given actions is available and enabled, so a submenu can hide when none of its items can run. If you replace a built-in action with a new object instead of spreading it, it loses its gating, and a toggle's checkbox always shows as unchecked. ([#11038](https://github.com/tldraw/tldraw/pull/11038))
- `TldrawUiMenuActionItem` now disables itself when its action's `isEnabled` returns false, so custom menus that render built-in actions grey them out when they can't run. The public menu item wrappers, such as `GroupMenuItem`, `FrameSelectionMenuItem` and `ArrangeMenuSubmenu`, now also hide outside the select tool, where their actions do nothing. ([#11038](https://github.com/tldraw/tldraw/pull/11038))
- Add a `ThrottledFunction<T>` type to `@tldraw/utils` for annotating the result of `throttle`. `throttle` now returns this type, with the same runtime behavior. ([#10927](https://github.com/tldraw/tldraw/pull/10927))
- Add `startCommentAt(editor, point)` to `@tldraw/commenting` for starting a comment thread at a specific canvas location from outside the comment tool. ([#10970](https://github.com/tldraw/tldraw/pull/10970))
- `TLSocketRoom.handleSocketMessage(sessionId, message, socket?)`, `handleSocketClose(sessionId, socket?)`, and `handleSocketError(sessionId, socket?)` now accept an optional originating socket parameter so messages and events from superseded connections are ignored. ([#11067](https://github.com/tldraw/tldraw/pull/11067))
- Add `LaserTool.startScribble()` which adds a laser scribble to the current session, starting a fresh session if none is active. ([#10781](https://github.com/tldraw/tldraw/pull/10781))

## Improvements

- Menus no longer offer actions that would do nothing: grouping locked shapes, flipping a locked shape, unlocking when nothing is locked, exporting all shapes on an empty page, moving to a new page at the page limit, and grouping an arrow away from a shape it's bound to. The main menu hides Paste, instead of disabling it, in browsers that can't read the clipboard. ([#11038](https://github.com/tldraw/tldraw/pull/11038))
- Allow keyboard navigation (Tab, Ctrl/Cmd+arrow, and the "Move focus to canvas" button) to reach locked shapes again, so keyboard users can select and unlock them. ([#11134](https://github.com/tldraw/tldraw/pull/11134))
- Add a **Comment** item to the default canvas context menu when commenting is configured. It opens the comment composer where you right-clicked. ([#11095](https://github.com/tldraw/tldraw/pull/11095))
- Move the comments filter menu to the right of the hide comments toggle in the comments panel header. ([#11135](https://github.com/tldraw/tldraw/pull/11135))
- Cancel comment draft placement and return to the select tool when clicking the canvas, instead of moving the draft comment. ([#10969](https://github.com/tldraw/tldraw/pull/10969))
- Draw the hinted outline around shapes, such as a frame you're dragging a shape into, at 2px instead of 2.5px. ([#10952](https://github.com/tldraw/tldraw/pull/10952))
- Speed up `store.query.index()` and `store.query.ids()` updates by no longer allocating for each change. ([#10228](https://github.com/tldraw/tldraw/pull/10228))
