So far this release moves the SDK's UI strings to ICU MessageFormat, with `F` and `defineMessages` for declaring translatable strings next to the code that renders them. It also adds a Comment item to the context menu, lets keyboard navigation reach locked shapes, and fixes bugs in selection, resizing, undo, rich text, local persistence, the store, and sync.

## What's new

### ICU MessageFormat translations ([#8036](https://github.com/tldraw/tldraw/pull/8036))

The SDK's UI strings are now [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/) messages, formatted by react-intl. A message can pluralize or select on the values passed to it, so languages with several plural forms, such as Arabic, Polish and Russian, now get the right one. `useTranslation()`'s `msg` takes the values as a second argument:

```tsx
const msg = useTranslation()
msg('a11y.multiple-shapes', { num: count })
```

Declare your own strings next to the code that shows them with `defineMessages`, and render them with `F`, or pass a declared message to `msg` where you need a plain string. If the current locale has no translation, the message's `defaultMessage` is used:

```tsx
import { defineMessages, F, useTranslation } from 'tldraw'

const messages = defineMessages({
	close: { id: 'my-app.close', defaultMessage: 'Close' },
})

function CloseButton() {
	const msg = useTranslation()
	return (
		<button aria-label={msg(messages.close)}>
			<F {...messages.close} />
		</button>
	)
}
```

`@tldraw/editor` can now translate too, through `translateMessage` and the editor's `TLI18nAdapter`, so its error screen is no longer English-only. Shapes name themselves for screen-reader announcements with the new `ShapeUtil.getShapeName()`. `overrides.translations`, your own translation keys, and self-hosted `assetUrls.translations` all still work as before. See [Internationalization](/sdk-features/internationalization).

## API changes

- 💥 **English translations** are no longer fetched from `assetUrls.translations.en`. The English strings now come from the SDK's declared messages, so pointing that url at your own file no longer rewords the UI. Use `overrides.translations.en` instead. ([#8036](https://github.com/tldraw/tldraw/pull/8036))
- Add a `ThrottledFunction<T>` type to `@tldraw/utils` for annotating the result of `throttle`. `throttle` now returns this type, with the same runtime behavior. ([#10927](https://github.com/tldraw/tldraw/pull/10927))
- Add `isAvailable(editor)`, `isEnabled(editor)` and `isChecked(editor)` to actions. Menu items built with `TldrawUiMenuActionItem` and `TldrawUiMenuActionCheckboxItem` read them: an unavailable action is hidden, a disabled one is greyed out or hidden depending on `whenDisabled: 'hide' | 'disable'`. `useSomeActionsEnabled` returns whether any of the given actions is available and enabled, so a submenu can hide when none of its items can run. If you replace a built-in action with a new object instead of spreading it, it loses its gating, and a toggle's checkbox always shows as unchecked. ([#11038](https://github.com/tldraw/tldraw/pull/11038))
- `TldrawUiMenuActionItem` now disables itself when its action's `isEnabled` returns false, so custom menus that render built-in actions grey them out when they can't run. The public menu item wrappers, such as `GroupMenuItem`, `FrameSelectionMenuItem` and `ArrangeMenuSubmenu`, now also hide outside the select tool, where their actions do nothing. ([#11038](https://github.com/tldraw/tldraw/pull/11038))
- `TLSocketRoom.handleSocketMessage()`, `handleSocketClose()` and `handleSocketError()` now take an optional `socket` argument, the socket the event came from. Hosts that forward socket events themselves, such as Bun.serve or Cloudflare hibernation, should pass it so that messages, closes and errors from a socket replaced by a reconnect under the same session id are ignored. ([#11067](https://github.com/tldraw/tldraw/pull/11067))
- Add `LaserTool.startScribble()`, which adds a laser scribble to the current session, or starts a new session if none is active. ([#10781](https://github.com/tldraw/tldraw/pull/10781))
- Add `startCommentAt(editor, point)` to `@tldraw/commenting` for starting a comment at a page point from outside the comment tool. ([#10970](https://github.com/tldraw/tldraw/pull/10970))
- Add `'italic'`, `'code'` and `'highlight'` to the rich text operations reported to `onUiEvent`. These buttons previously reported the wrong operation. ([#11018](https://github.com/tldraw/tldraw/pull/11018))

## Improvements

- Add a **Comment** item to the default canvas context menu when commenting is set up. It opens the comment composer where you right-clicked. ([#11095](https://github.com/tldraw/tldraw/pull/11095))
- Clicking the canvas while writing a new comment now cancels it and returns to the select tool, instead of moving the comment. ([#10969](https://github.com/tldraw/tldraw/pull/10969))
- Move the comments filter menu to the right of the hide comments toggle in the comments panel header. ([#11135](https://github.com/tldraw/tldraw/pull/11135))
- Menus no longer offer actions that would do nothing: grouping locked shapes, flipping a locked shape, unlocking when nothing is locked, exporting all shapes on an empty page, moving to a new page at the page limit, and grouping an arrow away from a shape it's bound to. The main menu hides Paste, instead of disabling it, in browsers that can't read the clipboard. ([#11038](https://github.com/tldraw/tldraw/pull/11038))
- Draw the hinted outline around shapes, such as a frame you're dragging a shape into, at 2px instead of 2.5px. ([#10952](https://github.com/tldraw/tldraw/pull/10952))
- Speed up `store.query.index()` and `store.query.ids()` updates by no longer allocating for each change. ([#10228](https://github.com/tldraw/tldraw/pull/10228))
