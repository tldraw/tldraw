This release exports TipTap's extension API from `tldraw`, so a custom rich text extension no longer needs its own `@tiptap/*` install, and teaches `npm create tldraw .` to scaffold into the current directory. The rest is a broad reliability pass across the SDK, with around seventy fixes to the select tool, the camera, shapes, exports, the store and signals layers, sync, and mermaid conversion. `Editor.setCamera` now rejects non-finite values instead of quietly coercing them.

## What's new

### TipTap's extension API is exported from tldraw ([#10691](https://github.com/tldraw/tldraw/pull/10691))

Customizing rich text through `options.text.tipTapConfig.extensions` has always been public API, but the classes you need to build an extension weren't exported. You had to add `@tiptap/core` to your own `package.json`, and a version that didn't dedupe against the one tldraw bundles gave you a second ProseMirror — which throws when the schema is built, not when you install it.

`Node`, `Mark`, `Extension`, `mergeAttributes` and `getSchema` now come out of `tldraw` itself, along with the `Extensions` and `JSONContent` types, so they're single-instance by construction and locked to the TipTap version tldraw ships.

```tsx
// Before
import { Mark, mergeAttributes } from '@tiptap/core'
import { Tldraw, tipTapDefaultExtensions } from 'tldraw'

// After
import { Mark, Tldraw, mergeAttributes, tipTapDefaultExtensions } from 'tldraw'
```

TipTap's `TaskList` and `TaskItem` extensions are exported too. They aren't in the default extension set, and tldraw doesn't style their checkboxes.

## API changes

- 💥 **`Editor.setCamera`** now throws on a non-finite `x`, `y`, or `z` instead of silently coercing it to `0` or the current zoom level, and no longer mutates the point object passed to it. ([#9903](https://github.com/tldraw/tldraw/pull/9903))
- 💥 **`store.query.filterHistory()`** now returns a change counter that no longer always equals `store.history.get()`. After a rolled-back transaction it can be ahead of the store's counter, and it reports a change even for record types the transaction didn't touch. ([#10200](https://github.com/tldraw/tldraw/pull/10200))
- Add `MESSAGE_TOO_LARGE` to `TLSyncErrorCloseEventReason`. A client receives it as the `reason` on a fatal sync error when a chunked message is too large to assemble, either because the server rejected the session or because the adapter refused to send. Apps that switch on the reason to pick an error message will want a case for it. ([#10810](https://github.com/tldraw/tldraw/pull/10810))
- Add `LruCache.delete(key)` to `@tldraw/utils`. ([#10338](https://github.com/tldraw/tldraw/pull/10338))
- Add an optional `background` flag to `MermaidBlueprintNode`. `renderBlueprint` sends flagged nodes behind the blueprint's lines, in blueprint order, so a filled node can span lifelines without hiding them. ([#10813](https://github.com/tldraw/tldraw/pull/10813))
- Add `anchorStartX` and `anchorEndX` to `MermaidBlueprintEdge`, the horizontal counterparts to the existing `anchorStartY` and `anchorEndY`. ([#10773](https://github.com/tldraw/tldraw/pull/10773))
- `Group2d.transform` now matches the base `Geometry2d.transform` signature, taking a `MatModel` and an optional options argument. ([#10603](https://github.com/tldraw/tldraw/pull/10603))
- `JsonChunkAssembler.state` gains a required `charsReceived` field on its non-idle branch, so code that builds a non-idle state by hand no longer type-checks. Reading `state` is unaffected. ([#10810](https://github.com/tldraw/tldraw/pull/10810))

## Improvements

- `npm create tldraw .` now scaffolds into the current directory, with a prompt when the directory isn't empty. ([#10657](https://github.com/tldraw/tldraw/pull/10657))

- Fix a crash when a shape was deleted between pointing at it and starting to drag it or one of its handles. ([#10179](https://github.com/tldraw/tldraw/pull/10179))
- Fix a crash when a shape being translated, or the frame it was being dragged over, was deleted mid-drag. ([#10171](https://github.com/tldraw/tldraw/pull/10171))
- Fix the select tool bailing to an old history mark, or crashing, when a resize started with nothing selected. ([#10165](https://github.com/tldraw/tldraw/pull/10165))
- Fix draw and highlight shapes created with no segments throwing in geometry and rendering. ([#10224](https://github.com/tldraw/tldraw/pull/10224))

### Geometry

- Fix geometry hit tests, nearest-point, and length calculations losing precision after a shape's SVG path data was generated. `getSvgPathData` rounded the geometry's stored points to two decimals in place, and geometries are cached per shape, so every later calculation used the rounded points. ([#10600](https://github.com/tldraw/tldraw/pull/10600))
- Fix `Group2d.transform` dropping its ignored children, resetting the `isInternal`, `excludeFromShapeBounds`, and `isEmptyLabel` flags, and discarding its `opts` argument. It now matches the base `Geometry2d.transform` signature. ([#10603](https://github.com/tldraw/tldraw/pull/10603))

### Sync

- Reject chunked sync messages that exceed a size or chunk-count limit instead of buffering them indefinitely. A message too large to assemble now fails with a `MESSAGE_TOO_LARGE` sync error instead of disconnecting the client in a loop. ([#10810](https://github.com/tldraw/tldraw/pull/10810))
- Fix sync stalling permanently when `getUri` rejected, which in the documented `useSync` pattern is an auth-token fetch. A rejected `getUri` is now retried on the normal backoff, and a closed `ClientWebSocketAdapter` no longer notifies listeners or reconnects after disposal. ([#10107](https://github.com/tldraw/tldraw/pull/10107))
- Fix `useSync` still reporting a previous room's error after the `uri` changed to a new, healthy room. ([#10108](https://github.com/tldraw/tldraw/pull/10108))
- Fix `TLSocketRoom.updateStore` not seeing or deleting object-lane records. ([#10114](https://github.com/tldraw/tldraw/pull/10114))
- Fix authorizer errors and vetoes being swallowed when `TLSocketRoom` was created without a `log` option. ([#10117](https://github.com/tldraw/tldraw/pull/10117))
- Fix `TLSocketRoom.closeSession` leaving the socket open when the close reason is over 123 bytes. The reason is now truncated and ends with `... (+N bytes)`. ([#10116](https://github.com/tldraw/tldraw/pull/10116))
- Fix text arriving corrupted when a message chunk boundary split a surrogate pair, such as an emoji. ([#10119](https://github.com/tldraw/tldraw/pull/10119))
- Fix `TLSyncRoom.close()` leaving per-session timers that could send into closed sockets or emit `session_removed` and `room_became_empty` on a closed room. A socket that throws on close no longer leaves the rest open. ([#10120](https://github.com/tldraw/tldraw/pull/10120))
- Fix `SQLiteSyncStorage` tombstone pruning throwing from a timer after the host closed the database, and make the prune transactional so a failure part-way cannot leave the history start ahead of the surviving tombstones. ([#10112](https://github.com/tldraw/tldraw/pull/10112))
- Fix large rooms failing to load in `InMemorySyncStorage`. ([#10110](https://github.com/tldraw/tldraw/pull/10110))
