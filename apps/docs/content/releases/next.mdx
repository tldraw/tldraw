This release adds a `center` operation to `Editor.alignShapes` and reactive `getOrInsert` methods on `AtomMap`, and deprecates `useViewportHeight`. It also fixes a batch of crashes and interaction bugs across sync reconnection, wheel input, modifier keys, frames, and bookmarks.

## API changes

- 🔜 **`useViewportHeight()`** is deprecated. Read `window.visualViewport` directly instead. ([#9826](https://github.com/tldraw/tldraw/pull/9826))
- Add `'center'` as an `Editor.alignShapes()` operation, which centers shapes on both axes at once. ([#9074](https://github.com/tldraw/tldraw/pull/9074))
- Add `getOrInsert()` and `getOrInsertComputed()` to `AtomMap`, matching the `Map` methods added in newer JavaScript runtimes. Both are reactive, and the callback only runs when the key is absent. ([#9752](https://github.com/tldraw/tldraw/pull/9752))

## Improvements

- Reduce per-pointer-event allocations in `Group2d` and `Editor` hit testing. ([#8600](https://github.com/tldraw/tldraw/pull/8600))

## Bug fixes

- Fix background tabs repeatedly dropping and re-establishing their sync connection when the browser throttles their timers. ([#9964](https://github.com/tldraw/tldraw/pull/9964))
- Fix a crash when panning with the wheel if the browser reported a non-finite wheel delta. ([#9586](https://github.com/tldraw/tldraw/pull/9586))
- Fix a crash when computing a frame's geometry if its heading text couldn't be measured yet. ([#9496](https://github.com/tldraw/tldraw/pull/9496))
- Fix modifier keys (shift, alt, ctrl, cmd) briefly being treated as held at the start of a click or drag right after being released, which could momentarily affect snapping. ([#9523](https://github.com/tldraw/tldraw/pull/9523))
- Fix undo after a cut also reverting the change made before it. ([#9920](https://github.com/tldraw/tldraw/pull/9920))
- Fix **Flatten to image** producing different groupings depending on selection order, and not merging clusters that were connected only through a bridging shape. ([#8661](https://github.com/tldraw/tldraw/pull/8661))
- Fix pasted links showing a broken preview image when the linked page has no Open Graph image. ([#9909](https://github.com/tldraw/tldraw/pull/9909))
- Fix collaborator rows in the people menu not lining up with your own row. ([#9900](https://github.com/tldraw/tldraw/pull/9900))
- Fix the spacing around the cursor chat item in the context menu. ([#9921](https://github.com/tldraw/tldraw/pull/9921))
- Fix the comment thread popover briefly rendering with a doubled shadow the first time a thread is opened. ([#9886](https://github.com/tldraw/tldraw/pull/9886))
- Fix the rotate counterclockwise tooltip not showing its comma key. ([#9772](https://github.com/tldraw/tldraw/pull/9772))
