So far this release moves the SDK's UI strings to ICU MessageFormat, adds a `ThrottledFunction` type to `@tldraw/utils`, hides menu actions that can't run, and adds a **Comment** item to the default context menu. It also fixes bugs in resizing, undo, page duplication, local persistence, the store, and sync.

## What's new

### ICU MessageFormat for UI strings ([#8036](https://github.com/tldraw/tldraw/pull/8036))

The SDK's UI strings now use [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/), so a message can pluralize or select on the values passed to it. The `msg` function returned by `useTranslation` takes an optional `values` argument, and accepts a declared message as well as a key:

```tsx
import { defineMessages, F, useTranslation } from 'tldraw'

const messages = defineMessages({
	shapes: { id: 'my-app.shapes', defaultMessage: '{count, plural, one {# shape} other {# shapes}}' },
})

function ShapeCount({ count }: { count: number }) {
	const msg = useTranslation()
	return <span title={msg(messages.shapes, { count })}>{count}</span>
}

function ShapeCountLabel({ count }: { count: number }) {
	return <F {...messages.shapes} values={{ count }} />
}
```

`defineMessages` declares a message with its English next to the code that shows it, `F` renders one as an element, and `useTldrawI18n` returns the i18n adapter behind both. `@tldraw/editor` gets `defineMessages` and `translateMessage` too, so its error fallback and other strings are now translated.

Existing overrides keep working: `overrides.translations`, your own translation keys, and self-hosted `assetUrls.translations` files are all read as before. One thing changes: the SDK no longer fetches an English translation file, because the English now comes from the declared messages. If you pointed `assetUrls.translations.en` at your own file to reword SDK strings, use `overrides.translations.en` instead. See [Internationalization](/sdk-features/internationalization) for details.

## API changes

- Add a `ThrottledFunction<T>` type to `@tldraw/utils` for annotating the result of `throttle`. `throttle` now returns this type, with the same runtime behavior. ([#10927](https://github.com/tldraw/tldraw/pull/10927))
- Add `isAvailable(editor)`, `isEnabled(editor)` and `isChecked(editor)` to actions. Menu items built with `TldrawUiMenuActionItem` and `TldrawUiMenuActionCheckboxItem` read them: an unavailable action is hidden, a disabled one is greyed out or hidden depending on `whenDisabled: 'hide' | 'disable'`. `useSomeActionsEnabled` returns whether any of the given actions is available and enabled, so a submenu can hide when none of its items can run. If you replace a built-in action with a new object instead of spreading it, it loses its gating, and a toggle's checkbox always shows as unchecked. ([#11038](https://github.com/tldraw/tldraw/pull/11038))
- `TldrawUiMenuActionItem` now disables itself when its action's `isEnabled` returns false, so custom menus that render built-in actions grey them out when they can't run. The public menu item wrappers, such as `GroupMenuItem`, `FrameSelectionMenuItem` and `ArrangeMenuSubmenu`, now also hide outside the select tool, where their actions do nothing. ([#11038](https://github.com/tldraw/tldraw/pull/11038))
- Add `startCommentAt` to `@tldraw/commenting` for starting a comment at a page point from outside the comment tool. ([#10970](https://github.com/tldraw/tldraw/pull/10970))
- `TLDefaultExternalContentHandlerOpts.msg` now has its own `(id, values?) => string` type instead of `ReturnType<typeof useTranslation>`. ([#8036](https://github.com/tldraw/tldraw/pull/8036))

## Improvements

- Menus no longer offer actions that would do nothing: grouping locked shapes, flipping a locked shape, unlocking when nothing is locked, exporting all shapes on an empty page, moving to a new page at the page limit, and grouping an arrow away from a shape it's bound to. The main menu hides Paste, instead of disabling it, in browsers that can't read the clipboard. ([#11038](https://github.com/tldraw/tldraw/pull/11038))
- Draw the hinted outline around shapes, such as a frame you're dragging a shape into, at 2px instead of 2.5px. ([#10952](https://github.com/tldraw/tldraw/pull/10952))
- Speed up `store.query.index()` and `store.query.ids()` updates by no longer allocating for each change. ([#10228](https://github.com/tldraw/tldraw/pull/10228))
- Add a **Comment** item to the default canvas context menu when commenting is set up. It opens the composer where you right-clicked. ([#11095](https://github.com/tldraw/tldraw/pull/11095))
- Cancel a new comment and return to the select tool when you click the canvas while writing it, instead of moving the comment. ([#10969](https://github.com/tldraw/tldraw/pull/10969))
- Move the comments filter menu to the right of the hide comments toggle in the comments panel header. ([#11135](https://github.com/tldraw/tldraw/pull/11135))
- Let keyboard navigation (Tab, Ctrl/Cmd+arrow and the "Move focus to canvas" button) reach locked shapes again, so keyboard users can select and unlock them. `getCurrentPageShapesInReadingOrder` includes locked shapes again. Clicking, brushing and select all still skip them. ([#11134](https://github.com/tldraw/tldraw/pull/11134))
