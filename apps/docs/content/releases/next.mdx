This release adds a `ThrottledFunction` type to `@tldraw/utils` and continues the reliability work from v5.5, with fixes to the store, sync, local persistence, resizing, cursors, and page duplication.

## API changes

- Add a `ThrottledFunction<T>` type to `@tldraw/utils` for annotating the result of `throttle`. `throttle` is now declared by `@tldraw/utils` rather than re-exported from `lodash.throttle`, with the same runtime behavior and signature. ([#10927](https://github.com/tldraw/tldraw/pull/10927))

## Improvements

- Reduce the thickness of hinted shape outlines, including the frame highlight shown while dragging shapes into a frame. ([#10952](https://github.com/tldraw/tldraw/pull/10952))
- Improve `store.query.index()` and `store.query.ids()` incremental updates so they no longer allocate per diff. ([#10228](https://github.com/tldraw/tldraw/pull/10228))

## Bug fixes

### Editor

- Fix flipped children of rotated selections getting the wrong rotation, repeated `onResizeStart` and `onResizeEnd` calls for unaligned shapes, and the fixed edge sliding when `resizeBox` hits `maxWidth` or `maxHeight`. ([#10351](https://github.com/tldraw/tldraw/pull/10351))
- Fix `setCursor` throwing for rotate and resize cursor types, and hex cursor colors breaking SVG cursors. ([#10350](https://github.com/tldraw/tldraw/pull/10350))
- Fix duplicated pages repositioning their shapes when the content was off screen, and use the duplicated page's own camera rather than the current page's. ([#10465](https://github.com/tldraw/tldraw/pull/10465))
- Fix held Cmd+Shift+arrow key combinations switching from parent and child selection to adjacent selection once the key repeats. ([#10184](https://github.com/tldraw/tldraw/pull/10184))
- Fix the arrow tool's precise mode carrying over to the next target. ([#10244](https://github.com/tldraw/tldraw/pull/10244))

### Store

- Fix reactions that write to the store re-running on every unrelated store change. ([#10236](https://github.com/tldraw/tldraw/pull/10236))
- Fix store changes made in the last frame before a listener is removed never reaching that listener. ([#10802](https://github.com/tldraw/tldraw/pull/10802))
- Fix undo restoring an intermediate state after a `put` that updated the same record twice. ([#10203](https://github.com/tldraw/tldraw/pull/10203))
- Fix `migrateStoreSnapshot` throwing instead of returning a migration error for malformed persisted schemas. ([#10220](https://github.com/tldraw/tldraw/pull/10220))
- Fix retroactive migrations rerunning on records when a persisted schema has a non-number sequence version. ([#10917](https://github.com/tldraw/tldraw/pull/10917))

### Persistence and sync

- Fix edits being lost when an editor remounts on the same persistence key while the previous client is still saving. ([#10752](https://github.com/tldraw/tldraw/pull/10752))
- Fix `undefined` record values kicking the session with `INVALID_RECORD`, and ignore `__proto__` keys in incoming diffs. ([#10118](https://github.com/tldraw/tldraw/pull/10118))
- Fix clients on protocol version 7 silently desyncing when sent string append ops. ([#10095](https://github.com/tldraw/tldraw/pull/10095))
- Fix a resumed session on a hibernating host skipping the handshake's schema checks, so a session the server could no longer reconcile after a redeploy was served unmigrated diffs. It is now rejected with `SERVER_TOO_OLD` or `CLIENT_TOO_OLD`. ([#10122](https://github.com/tldraw/tldraw/pull/10122))
