Compare a few Mermaid diagrams drawn with normal arrows, with elbow arrows, and as pele's own SVG.

---

`@tldraw/mermaid` lays diagrams out with [pele](https://pele.run) and draws edges as normal curved arrows. This example also draws flowcharts and state diagrams with elbow arrows that follow pele's right-angled routes, an experimental option, so the two can be judged side by side against pele's own rendering.

Click the button in the top panel to draw three diagrams of each type in a grid: one row per diagram, one column per drawing.
