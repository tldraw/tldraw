Add your own actions to the menus on libraries and their items.

---

The `LibraryMenu` and `ItemMenu` overrides render the default menus with extra `LibraryMenuItem`s as children: "Copy link" and "Export as JSON", which copy to the clipboard and confirm with a toast. The default actions stay in place.
