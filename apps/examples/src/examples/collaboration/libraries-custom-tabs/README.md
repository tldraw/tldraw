Customize the libraries panel's owner tabs, library headers and empty state.

---

With two or more owners, the panel shows a tab per owner. The `LibraryTabLabel` override adds a count of the tab's libraries, `LibrarySectionHeader` adds a count of each library's items, and `NoLibraries` replaces the empty Personal tab's message with a button that creates the first library.
