Every variation of a comment list row, thread comment and notification row, side by side, for checking spacing and edge cases.

---

`CommentsList` and `CommentThread` are presentational: they take already-summarized items, so this example feeds them fixtures instead of comment records. Each panel groups one kind of variation, such as long text, long names, the meta row, reactions and row states. The last section shows the tldraw.com notifications popover, which reuses the list with its own row. Drag the width slider to see how the rows wrap in a narrower or wider panel, and tick the checkbox to check dark mode.
