Replace pieces of the libraries panel: its header menu, library headers and empty states.

---

The `LibrariesPanelHeader` override adds "Fold all" and "Unfold all" to the panel's ⋯ menu, `LibrarySectionHeader` adds a count of each library's items, and `EmptyLibrary` and `NoLibraries` replace the empty states' messages.
