Show library items as a list of rows instead of a grid of tiles.

---

Replacing `ItemTile` and `AddSelectionTile` turns each tile into a row with a thumbnail, the item's name and the date it was added. The `--tlui-libraries-columns` CSS variable, set to `1` on an element around the editor, makes the panel's grid a single column.
