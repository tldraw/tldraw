Hide parts of the libraries panel to leave a gallery of items to place.

---

Pass `null` for a piece of the panel in `LibrariesPanel`'s `components` prop to hide it. This example hides the header, the tile that adds the selection, and the menus on libraries and items, so the panel only places items.
